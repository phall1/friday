# Interface type

IBM Plex Sans, unmodified Regular, Medium and SemiBold TrueType files.
SIL Open Font License 1.1: see [OFL.txt](OFL.txt).

Source: [IBM/plex](https://github.com/IBM/plex/tree/bf260093582f04622aacc1e9f9ca604d7ccd0c42/packages/plex-sans/fonts/complete/ttf),
commit `bf260093582f04622aacc1e9f9ca604d7ccd0c42`.

Embedded at build time by `native/design.zig`; no font installation or network
request is needed at runtime. Regular is body copy, Medium is control/section
ink, and SemiBold is the wordmark. Geist Mono remains the telemetry face.
